# 0.2026267.2259 — fix(gh): quote the #GhDocument plan step so YAML does not truncate it

## Summary

Quote the `plugin-gh-document-self-test` plan step so YAML does not truncate it.

The step was written unquoted:

```yaml
- check: the embedded #GhDocument schema compiles, validates a sample, and serializes
```

In YAML, ` #` starts a **comment** (a `#` only escapes when not preceded by whitespace), so the parsed `check:` value was only `the embedded` — everything from `#GhDocument` on was silently dropped. Verified at the parser:

```
parsed check = "the embedded"                       # before
parsed check = "the embedded #GhDocument schema compiles, validates a sample, and serializes"   # after (quoted)
```

**Blast radius.** The docs generator projects a candy's `plan:` into the `## Acceptance plan` table of its `reference/candy/<repo>.md` page; the truncated value emitted a malformed page (`| check | the embedded |`). That is the artifact docs#130's validator caught. The defect is in the SOURCE manifest (introduced with the document op in #4), fixed here at its source.

Two files change: the manifest step (one scalar, now quoted) and the repo-root `charly.yml` bed (below).

```

$ git -C plugin-gh grep -c "retry\|Retry\|backoff" origin/main -- candy/plugin-gh/gh/'*.go'
```
